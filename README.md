# Годинникар

Гра для телефона: зберіть золотий кишеньковий годинник із деталей, а потім заведіть його, і він покаже справжній час.

Це власна реалізація ідеї гри Watchmaker PRO. Код, 3D-деталі, тексти й звуки створені тут заново, з оригіналу нічого не скопійовано. Назву й графіку оригіналу не використано.

## Як запустити

Збирати нічого не треба, потрібен лише Node.js для локального сервера.

```bash
npm start
```

Гра відкриється на http://localhost:8123.

Щоб спробувати на телефоні в тій самій мережі Wi-Fi:

```bash
npm run start:lan
```

Так гра працює, але не встановлюється: для встановлення й офлайн-режиму браузер вимагає HTTPS, тобто розміщення на хостингу, наприклад GitHub Pages.

## Тести

```bash
npm test
```

## Будова

- `src/game/`: правила, каталог деталей, геометрія й кінематика механізму, без жодної графіки.
- `src/render/`: сцена Three.js і деталі, згенеровані кодом.
- `src/ui/`: жести, звук.
- `src/main.js`: зв'язує все це з інтерфейсом.
- `sw.js`: офлайн-кеш. Змінюючи будь-який файл гри, збільшуйте `VERSION`, інакше встановлена гра не оновиться.
- `vendor/`: Three.js 0.170.0 (ліцензія MIT).
